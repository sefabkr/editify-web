Editify

The offline PDF editor for iPhone and iPad

Editify is a PDF editor for iPhone and iPad. Editing, OCR, and document conversion run on your device without uploading your files to a conversion server. Web-page conversion, optional signature timestamps, App Store purchases, and sharing you request can use the network.

What's inside

  • Merge, split, extract, rotate, crop, compress PDFs
  • Convert images, Word, RTF, web pages, camera scans → PDF
  • Convert PDF → editable Word text (DOCX), or keep each page as an image; export PDF pages as PNG/JPG
  • OCR (searchable PDFs) in languages supported by your device, fully on-device
  • Sign PDFs (draw / type / image / X.509 certificate)
  • AES password protect, watermarks, page numbers, metadata
  • Full PDF editor with text, image, drawing, shapes
  • Annotations: highlight, underline, sticky notes, free text

Try a complete task

Version 1.2 includes three successful exports without an Editify watermark, once per installation. A batch created in one operation counts as one export. Previews, failed attempts, and canceled shares do not use an export; sharing the same completed output again does not use another.

After the three exports, you can continue reading, processing, and previewing documents in private app storage. Pro is required to deliver a new output, including saving to the app library, sharing, printing, saving images to Photos, or copying newly generated text. Monthly and yearly subscriptions are the main Pro options, with a separate lifetime purchase in Settings. Existing purchases remain supported; prices and any eligible offers come from the App Store.

PDF-to-Word text mode creates editable text and uses local OCR for scanned pages. It does not reconstruct tables, images, or complex layouts. The separate appearance mode inserts page images whose text is not editable. Review the result before using it.

Built with care

  • 100% native Apple frameworks — no third-party SDKs
  • Core document tools work offline; no automatic analytics uploads or tracking SDKs
  • Available in 12 languages
  • Requires iOS 17.0 or later
